# Resume Setup Instructions

## Quick Setup (Recommended)

The easiest way to add your resume is to place it in the `public` folder:

1. **Prepare your resume:**
   - Make sure your resume is in PDF format
   - Name it `resume.pdf`

2. **Add to project:**
   - Place the file in: `d:\Careers\workspace-portfolio\public\resume.pdf`

3. **Done!**
   - The "Download Resume" button will automatically work
   - No code changes needed

---

## Alternative: Supabase Storage (Optional)

If you prefer to host your resume on Supabase:

### Step 1: Create Storage Bucket
1. Go to your Supabase Dashboard
2. Navigate to **Storage** in the sidebar
3. Click **"New bucket"**
4. Name it `resumes`
5. Make it **Public** (toggle the switch)
6. Click **Create bucket**

### Step 2: Upload Resume
1. Click on the `resumes` bucket
2. Click **"Upload file"**
3. Select your `resume.pdf`
4. Click **Upload**

### Step 3: Get Public URL
1. Click on the uploaded file
2. Click **"Copy URL"** or **"Get public URL"**
3. You'll get a URL like:
   ```
   https://uwmvsswuudrrxwmsyrdh.supabase.co/storage/v1/object/public/resumes/resume.pdf
   ```

### Step 4: Update Code
1. Open `components/About.tsx`
2. Find line 42:
   ```typescript
   href="/resume.pdf"
   ```
3. Replace with your Supabase URL:
   ```typescript
   href="https://uwmvsswuudrrxwmsyrdh.supabase.co/storage/v1/object/public/resumes/resume.pdf"
   ```

---

## Testing

After adding your resume:
1. Go to http://localhost:3000
2. Scroll to the "About Me" section
3. Click the "Download Resume" button
4. Your PDF should download

---

## Troubleshooting

**Button doesn't work:**
- Check that the file is named exactly `resume.pdf`
- Make sure it's in the `public` folder
- Restart the dev server: `npm run dev`

**Supabase URL not working:**
- Verify the bucket is set to **Public**
- Check the URL is correct (no typos)
- Make sure the file uploaded successfully

---

**Recommendation:** Use the public folder method for simplicity. Only use Supabase if you need to update your resume frequently without redeploying.
