### 2. Profile Image
**File:** `public/profile.jpg`

**What to do:**
1. Prepare a professional photo of yourself (square/portrait orientation works best)
2. Save it as `profile.jpg`
3. Place it in the `public` folder: `d:\Careers\workspace-portfolio\public\profile.jpg`

**Tips:**
- Use a high-quality image (at least 800x800px)
- Square aspect ratio looks best
- Professional headshot or casual professional photo
- Good lighting and clear background

**Alternative:** If you want to use a different filename or format:
- Open `app/page.tsx`
- Find line 44: `src="/profile.jpg"`
- Change to your filename: `src="/your-photo.png"`

## 📄 Resume Setup

### Option 1: Simple PDF in Public Folder (Recommended)
1. Place your resume PDF in the `public` folder
2. Name it `resume.pdf`
3. The download button will automatically work!

**File location:** `public/resume.pdf`

### Option 2: Use Supabase Storage
If you want to use Supabase to host your resume:

1. Go to Supabase Dashboard → Storage
2. Create a new bucket called `resumes` (make it public)
3. Upload your PDF file
4. Copy the public URL
5. Update `components/About.tsx` line 42:
   ```typescript
   href="YOUR_SUPABASE_STORAGE_URL"
   ```

## 🖼️ Adding Projects

Add projects directly in your Supabase table:

**Required fields:**
- `title` - Project name
- `description` - Brief description
- `image_url` - Full URL (e.g., `https://files.catbox.moe/abc123.jpg`)
- `project_link` - Project URL (optional)
- `tags` - Single tag or array (optional)

**Example:**
```
title: "E-commerce Platform"
description: "A full-stack online store with payment integration"
image_url: "https://files.catbox.moe/46jf13.jpeg"
project_link: "https://myproject.com"
tags: "React"
```

## 🎨 Color Customization

### Changing the Color Scheme
**File:** `app/globals.css`
**Lines:** 5-17

The site uses Zinc colors by default. To change:
1. Replace `--color-zinc-XXX` with another Tailwind color
2. Options: `slate`, `gray`, `neutral`, `stone`, `red`, `blue`, etc.

Example for Blue theme:
```css
--color-blue-50: #eff6ff;
--color-blue-100: #dbeafe;
...
```

Then update all components to use `blue` instead of `zinc`:
- Find: `bg-zinc-`, `text-zinc-`, `border-zinc-`
- Replace with: `bg-blue-`, `text-blue-`, `border-blue-`

## 💡 Tips

1. **Keep it concise:** Recruiters spend ~6 seconds on a portfolio
2. **Use action verbs:** "Built", "Designed", "Implemented"
3. **Quantify results:** "Improved performance by 40%"
4. **Update regularly:** Add new projects as you complete them
5. **Test on mobile:** Most traffic comes from mobile devices

---

## 🆘 Need Help?

If something doesn't work:
1. Check the browser console (F12) for errors
2. Restart the dev server: `npm run dev`
3. Verify your Supabase credentials in `.env.local`
4. Make sure all file paths are absolute URLs
